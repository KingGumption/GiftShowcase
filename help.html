Setup & help

Get your overlay on stream.

Start with one design. Add a canvas when you need several overlays together.

1. Create, test and save

Open Studio and sign in. Choose an overlay, then use Add card to create a Gift, Follow, Likes or Share card. Set the action label and sound separately. Select a card in the stream preview or the card list to edit it. On a phone, Back to cards returns to the list. The Layout tab changes the arrangement; Style presets change colours and effects. Click Sample event or Test this card to see it respond. Save the design before using it on stream.

The Design library lets you search, duplicate or archive designs. Archive hides a design from normal selection without breaking existing Direct links or canvases. Version history can preview and restore earlier saves.

2. Direct link or Canvas?

A Direct link is one saved widget. Copy it into an Browser Source and use the displayed width and height. A Canvas combines several saved designs; use Canvas Designer to position them and copy the canvas link into one Browser Source.

Both links follow saved changes. Unpublished local drafts stay in your browser unless you choose Save or enable Live editing. If a second tab saves a newer version, Studio offers to load it, save your edits as a copy or deliberately replace it.

Keep link tokens private. Replacing a Direct link or canvas URL revokes the old URL; update it in your streaming software afterward. Open sample preview links show demonstration events and should not be used as your live source.

3. Connect TikFinity

Choose streaming software that supports a Browser Source: a webpage rendered inside your stream. For example, add a Browser Source in OBS Studio; other applications may use different control names. Use the Direct link or Canvas URL with the source dimensions shown in Studio.

  1. Run TikFinity on the same computer as your streaming software.
  2. Connect TikFinity to the live and enable its Event API.
  3. Load your saved widget or canvas URL in your streaming software. The live source connects to ws://localhost:21213/.
  4. If the browser asks for local-network access, allow it only when you want to connect to TikFinity. Public browsing and editor sample previews never require this connection.

If events do not arrive, check that the live is active, TikFinity is connected, its Event API is enabled and a firewall has not blocked the local connection. A cloud-hosted webpage cannot discover a live on another person’s computer through your localhost connection.

No sound?

Check that the card has a sound, its volume is above zero, overlay sounds are enabled and the preview is unmuted. Preview mute affects the editor only. Enable Browser Source audio and the mixer in your streaming software.

Use Choose or upload sound for MP3, WAV or OGG source files up to 8 MiB. Trim to 30 seconds or less. Studio uploads a 24 kHz mono WAV clip. Your account stores up to 10 MiB and 50 sounds, including archived sounds retained for existing designs/history. Archived sounds can be restored from the sound library. Account deletion removes their stored audio.

A raw file path from your computer is not an upload and is not portable to another browser or browser source. Upload only audio you have permission to use.

Missing gift or image?

Search by name, TikTok gift ID, coin amount or a price range. Unknown prices are not treated as zero. Favourites and Recent can help find a gift again.

Gift lists vary by region and creator. The catalogue refreshes automatically from available sources, and connected live widgets can discover gift metadata. This does not guarantee every creator gift is available before it is sent. If updates fail, the last available list remains usable.

If a gift is missing, try its TikTok ID and check again after the catalogue refreshes. Existing cards keep their saved images. Keep your Direct link token and account password private.

Preview and layout checks

Previews automatically scale and centre your design. Sample events are enabled by default; switch them off to inspect a quiet state. Pause freezes animations without changing the design. Dark, Neutral and Light backgrounds are editing aids and do not change transparent browser-source output.

Rows show the selected number of cards visible at once. If there are extra cards, use Fit all, Scroll this row or Move extra cards. Canvas has numeric geometry, arrow-key nudging, alignment/distribution, an optional grid, safe-area guides and snap controls. Canvas changes are saved to the live output; Undo/Redo can recover recent layout changes.

Your account, drafts and links

Unsaved changes recover unpublished edits on this browser and are separated by account. Save your design to keep a server copy. Opening this guide and returning to Studio in the same tab keeps your existing sign-in.

Keep your password in a password manager. If a Direct link has been replaced or deleted, open its saved design in Studio and copy the current link. Account settings lets you download your data and manage your account.

Older supporter overlay

The legacy supporter preview remains available. Existing legacy URLs continue to work; its controls are separate from the five current Studio editors.

Useful diagnostics

In Studio’s account menu, Copy diagnostics shows a reviewable summary of build, overlay type, catalogue availability and viewport. It omits passwords, account email, viewer identities, design contents and Direct link tokens.
